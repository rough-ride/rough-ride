The change (uncommitted, see `git diff main` and `git status`) implements this request:
Let the gardener record watering. On the beds page, each bed gets a "Water now" button that records a watering with the current time, and a small form to record a past watering with a date and an amount in litres. Show when each bed was last watered on the beds page, list the five most recent waterings on the dashboard, and add a page that lists every watering with a filter by bed.

The app is running: web http://localhost:3795, API http://localhost:8795/api. Sign in with DEMO_EMAIL / DEMO_PASSWORD from the environment. The reported problem: The server checks future dates and stamps 'Water now' dates using its own time zone while the form uses the browser's today, so users ahead of the server have today's date rejected and dates can disagree with displayed times.
